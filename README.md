# Dotfiles

My personal collection of configuration files (dotfiles) for customizing Linux environments, window managers, shell setups, and desktop utilities.

## Features

- **Window Management & Status Panels**: Lightweight configurations for custom desktop environments.
- **Terminal & Shell**: Custom shell profiles, aliases, and terminal multiplexer settings.
- **Core Utilities**: Custom configurations for text editors and system monitoring tools.

## Quick Start

Clone the repository to your local setup:

```bash
git clone https://codeberg.org/mcnunes/dotfiles.git ~/.dotfiles
```
